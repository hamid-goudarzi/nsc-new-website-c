# Neil Smith Construction Ltd. website (Option C)

## Files
- `index.html` is the page (styles, scripts, logo and 3D project drawings built in)
- `media/` holds the photos and the hero video (1080p for desktop, 720p for phones)
- `nsc-logo.jpg` is used for the browser tab icon

Keep `media/` next to `index.html` when you upload.

## Publish with GitHub Pages
1. Upload everything (including the `media` folder) to the root of the repository.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, set Source to **Deploy from a branch**, choose `main` and `/ (root)`, then **Save**.
4. After a minute the site is live at `https://<your-username>.github.io/<repo-name>/`.

For your own domain, enter it under **Settings → Pages → Custom domain** and point your DNS to GitHub Pages.
